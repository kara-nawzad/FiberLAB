# Third-party notices

FiberLAB loads three typefaces from Google Fonts at runtime (`index.html`).
It does not vendor font binaries in this repository.

| Family         | Role                 | Licence                   | Upstream                                         |
| -------------- | -------------------- | ------------------------- | ------------------------------------------------ |
| Sora           | display / headings   | SIL Open Font License 1.1 | https://fonts.google.com/specimen/Sora           |
| Manrope        | body text            | SIL Open Font License 1.1 | https://fonts.google.com/specimen/Manrope        |
| JetBrains Mono | monospace / readouts | SIL Open Font License 1.1 | https://fonts.google.com/specimen/JetBrains+Mono |

The full licence text is available at
https://openfontlicense.org/open-font-license-official-text/

Copyright in each typeface remains with its respective authors. If the fonts
are later self-hosted, ship the upstream `OFL.txt` alongside the font files.
